## Title

Hauska MCP: building code, accessibility standards, and site reasoning for your agent

## Stub

We ship a single MCP server (`https://mcp.hauska.dev/mcp`) with a free public catalog
and product-gated place/workspace and Layer 2 reasoning tools. The deployed registry
exposes 46 tools. Every catalog answer cites an atom — not a paraphrase.

**Corpus honesty:** ~478 public-free atoms across 2 jurisdictions (Bastrop, Grand
County/Moab) plus ADA 2010 and the FHA Design Manual under the
`federal-accessibility-standards` tenant. Thirty-two platform-internal jurisdictions
are never marketed as public-free.

**Data packages** organize the sellable surface:

- **Subsurface** — assess subsurface risk; raw SSURGO/USGS stays Layer 1 free
- **Hydrology / flood** — simulate drainage and flood exposure; FEMA/NOAA tables stay free
- **Parcel / property** — reason a parcel brief; Regrid baseline stays free
- **Code / plan-review** — reconcile precedence across ADA/FHA/I-Codes; code text stays free
- **Environmental** — roadmap (EJ context teaser only today)

Place dossier is Central TX pilot scope only. Confidence scores are cited raw LLM
emissions; calibration is in progress.

Docs: https://hauska.dev/mcp
