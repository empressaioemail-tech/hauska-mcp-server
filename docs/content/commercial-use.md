# Commercial use

The Hauska MCP **public catalog** (Layer 1 code atoms) is free for non-commercial use
and small-scale commercial use on consuming products below the stated MAU threshold
on [Pricing](pricing.html).

Commercial use above that threshold requires a paid tier (Developer Pro, Team, or
Embedder License). Enforcement is operational at v1 — we surface high-volume free-tier
candidates in logs for outreach; there is no automated Stripe signup in this release.

**Product-gated tools** (place, workspace, Codex, Cortex) are governed by your API key
agreement with Hauska. Do not redistribute raw parcel geometry or Regrid-sourced layers
outside your licensed use.

Questions: support@hauska.dev
