Municipal codes are public records. The Service retrieves and structures

provided "as is", without warranty. Code text changes, and ingestion can
lag or err. For any legal, permitting, or construction decision, verify
against the jurisdiction's official code of record. The provenance on
every atom (source document, URL, fetched-at, content hash) exists so you
can do exactly that.
