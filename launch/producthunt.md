**Name:** Hauska MCP Server

**Tagline (60 char max):**
Cited building-code answers for AI agents

**Topics:** Artificial Intelligence, Developer Tools, API, GovTech

**Description:**

Hauska MCP Server is a free public Model Context Protocol endpoint that
gives AI agents grounded answers about municipal building codes and
zoning. Every result is an atom with a stable id, a content hash, and its
source document, so agents cite the code instead of paraphrasing it.
Works with Claude Desktop, Claude Code, Cursor, and custom SDK agents.

**First comment (maker's note):**

We built this because agents doing real construction, permitting, and
real-estate work need answers traceable to the actual code, not
plausible-sounding guesses. The public catalog is free, needs no key, and
every answer carries a citation chain. Docs and quickstarts at
mcp.hauska.dev/docs, and there is a runnable example agent in the repo.
We would love feedback from anyone building agents in the built-world
space.
