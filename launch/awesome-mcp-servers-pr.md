## PR description

```
Adds the Hauska MCP Server: a public, hosted MCP endpoint
(Streamable HTTP) for municipal building-code and zoning retrieval.

- Free public catalog, no API key required.
- Every result carries provenance: a stable atom id, content hash,
  and the source document.
- Five catalog tools: search_atoms, get_atom, list_jurisdictions,
  query_jurisdiction, search_permit_atoms.
- Docs and quickstarts: https://mcp.hauska.dev/docs

Endpoint: https://mcp.hauska.dev/mcp
```
